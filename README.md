# Platform News Report

Platform News Report, a large-scale computational communication research project examining news content on TikTok, YouTube Shorts, and Instagram.

<https://ccsmainz.github.io/platformnews/>

A project of the [Computational Communication Research Group](https://ccs.ifp.uni-mainz.de) at the [Department of Communication](https://www.ifp.uni-mainz.de), Johannes-Gutenberg University Mainz, Germany.

Principle investigator: Michael Scharkow
